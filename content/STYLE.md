# thai-shadowing STYLE ガイド（最終版）

対象：`content/sets/S01〜S10.json` を起草する担当（人でもエージェントでも）と、`/thai` で `content/daily/YYYY-MM-DD.json` を作る Claude。
学習者：英介さん（バンコクの日系商社・営業系・タイ語初中級・前職は自動車プレス部品の品質保証マネージャー）。
教材形式：日本語 → 無音3秒（自分で言う）→ タイ語（-10%）→ 1.5秒 → タイ語（自然速度）→ 3秒。
目標：仕事の3場面「①上司の指示をスタッフに通訳する／自分が指示する」「②タイ人の客に納期・見積・製品を説明する」「③翻訳を頼まれて意味やニュアンスを説明する」で、日本語を聞いて3秒でタイ語が口から出ること。

---

## 0. 設計思想（迷ったらここに戻る）

この教材は「読んで覚える」ではなく「日本語を聞いて、3秒でタイ語が口から出る」ための音声ドリル。起草の優先順位は次の順で固定する。

1. **本当に口にする文**：バンコクの日系商社で、日本人営業・タイ人スタッフが実際に言う言い方。教科書調・直訳調・書き言葉を排除する。規則のために不自然な文を作らない。
2. **3秒で言い切れる長さ**：Level 判定の第一基準は音節数（§3）。長い文は2つに割る。1文＝1つの意図。二つの用件を1文に詰めない。
3. **骨格＋差し替え**：1セットの中で同じ骨格（例 ช่วย〜ด้วยนะครับ）を2〜3回、差し替え語だけ変えて出す。獲得させるのは「文」ではなく「型」。同じ骨格は隣り合わせにせず、間に別の文を挟む（セット内の間隔反復）。
4. **成功率7〜8割**：Level 1 を多めにし、Level 3 の直後は Level 1 に戻す。セットの最後は必ず易しい文で終える。
5. **新語は1文に2つまで**：Level 1 は0〜1語、Level 2 は1〜2語、Level 3 は2〜3語。それ以上は骨格が消える。
6. **一般化**：実在の社名・人名・型番・ブランド・価格・案件を入れない（§2.10）。公開リポジトリで配信する。

## 1. データ形式と機械チェック（守らないと `check` で止まる）

`content/daily/2026-09-26.json` と同じ形式。`check` は `build`／`daily`／`weekly` の前にも自動で走るので、**1文の不備で全エピソードの生成が止まる**。

### 1.1 1文のフィールド

| フィールド | 役割 | 制約（`tools/generate.py check`） |
|---|---|---|
| `id` | セットは `S03-05`（セット-連番、2桁）。daily は `D20260926-01` | sets・daily・weekly の全ファイルを通して重複禁止 |
| `jp` | 日本語。TTS（Keita）が読み、チャプター名（`01 jp ／ th`）にもなる | 空不可。禁止語なし |
| `th` | 表示用タイ語。数字・略語はそのままでよい（`1,500 ชิ้น`／`PO`） | 空不可。禁止語なし |
| `th_tts` | 読み上げ用タイ語（Niwat が読む） | **英字・数字・括弧・引用符（`A-Za-z0-9()[]"“”'‘’`）があると落ちる**。空も落ちる |
| `reading` | カタカナ読み | 正規表現 `^[゠-ヿ゙゚ーー・ 　]+$`。**カタカナ・ー・スペース以外は落ちる**（漢字・かな・英数字・「、」「。」「-」で落ちる。「・」「ヴ」は通るが §4 で使わない） |
| `note` | 「なぜその言い方か」 | 目標40字。**60字超で落ちる**。Python の `len` なのでタイ語の母音記号・声調記号も1字に数える |
| `tags` | `[場面, 機能]` の2つ（§1.2） | 空不可 |
| `level` | 1〜3（§3）。1＝まずこれ、2＝次、3＝余裕があれば | それ以外は落ちる |
| `done` | 任意。`true` で復習・週まとめから外れる（覚えた文） | — |

- 禁止語（`jp`・`th`・`note` を機械検査）：`tools/generate.py` の `FORBIDDEN` に列挙した社名（現勤務先・前職。この文書には書かない）。機械検査に無い実名（取引先名・メーカー名・ブランド・人名・実型番）も同じ扱いで入れない（§2.10）。`th_tts`・`reading`・`title` は検査対象外だが同じルール。
- `th` と `th_tts` は**語順・語彙を完全に一致**させる。違ってよいのは §5 の置換（数字→タイ語の語、略語→タイ文字、記号→語、誤読を直すスペース）だけ。学習者は「目で読んだ文」と「耳で聞く文」が同じでないと混乱する。`th` と同じ場合も `th_tts` を空にしない（コピーを入れる）。

### 1.2 tags の語彙（この中から1つずつ、`[場面, 機能]` の順）

- 場面：客先／社内／通訳／電話／会議／日常／翻訳
- 機能：依頼／確認／報告／説明／数字／品質／挨拶／謝罪／語彙／締切

### 1.3 セット直下

- `set`（`S01`）、`title`（8字以内の日本語見出し）、`title_th`（短いタイ語）、`sentences`。
- `title` はエピソード冒頭で Keita が「（title）。15文です。…」と**読み上げる**。記号・英字・「／」「〜」を入れない。`title_th` はショーノートに出るだけで読まれない。
- daily は `set`＝日付、`title`＝その日の見出し（例「納期の相談」）。§9 参照。

## 2. 全体の文体ルール

### 2.1 話者・一人称・文末

**話者**は男性・日本人の営業担当。通訳しているときも口から出るのは自分の声なので、女性上司の言葉を訳しても文末は **ครับ**。

**一人称**は **ผม** のみ（ฉัน／ดิฉัน／กระผม は不可）。タイ語は主語を落とす言語なので、主語として入れるのは3つの場合だけ：
- ①自分の意思・約束を明示する：ผมจะเช็คให้ครับ（私が確認します）
- ②上司・客と対比する：หัวหน้าบอกว่า…（上司が言うには…）に対して ผม…
- ③謝罪・断り：ผมต้องขอโทษด้วยครับ（申し訳ありません）

依頼文（ช่วย…）・確認（…ใช่ไหมครับ）・数字句には入れない。目的語の ผม（บอกผม＝私に言う、รายงานผม＝私に報告する）は自由。
**เรา** は単独の「私」で使わず、「うち＝会社」の意味で **ทางเรา／บริษัทเรา** だけ。

**文末**は **ครับ**。次の型に固定し、意味を揺らさない：

| 形 | 意味 | 例（日本語訳） |
|---|---|---|
| …ครับ | 言い切り・事実・返事 | ราคาขึ้นอยู่กับจำนวนครับ（価格は数量によります） |
| …นะครับ | 柔らげ（依頼・保留・約束の余韻・「〜しておきますね」） | ขอเช็คก่อนนะครับ（確認しますね） |
| ช่วย…ด้วยนะครับ／ด้วยครับ | 依頼の完了マーカー | ช่วยส่งให้ลูกค้าด้วยนะครับ（お客様に送ってください） |
| …ได้ไหมครับ | 可能性の質問・お願いベース | ช่วยถามผู้ผลิตให้หน่อยได้ไหมครับ（メーカーに聞いてもらえますか） |
| …ใช่ไหมครับ | 念押し確認（通訳で最頻出） | หมายถึงล็อตเดือนนี้ใช่ไหมครับ（今月のロットのことですね） |
| …ไหมครับ／…หรือเปล่าครับ | 有無・Yes/No の質問（หรือเปล่า の方が柔らかい） | สะดวกไหมครับ（ご都合よろしいですか） |
| …หรือยังครับ | 「もう〜しましたか」 | ได้รับอีเมลหรือยังครับ（メール届きましたか） |
| รับทราบครับ／ได้ครับ／โอเคครับ | 了解の返事 | รับทราบครับ（承知しました） |

- ครับ は1節に1つ。2節の文でも合計2回まで（ขอโทษครับ ช่วยพูดอีกครั้งได้ไหมครับ）。相づちの ครับ を文頭に置かない。
- S04 の「数字句だけ」の項目は ครับ を付けない（文ではない）。短文には付ける。
- 使わない：ครับผม（へりくだりすぎ・返事専用）、ค่ะ／คะ／นะคะ（女性形）、จ้า／จ๊ะ／คับ／ครัช、ป่ะ／ป่าว／อ่ะ／555（若者・チャットの砕け形）。ไหม は ไหม と書く（มั้ย にしない）。
- 質問文に「?」は付けない（疑問は ไหม／หรือเปล่า／หรือยัง が担う）。
- ๆ は前にスペースなし・後にスペース（ช้าๆ หน่อย）。
- 同じ文末が4文以上続かないように並べる（ด้วยนะครับ の連打は耳が慣れて骨格を聞かなくなる）。

### 2.2 相手別の丁寧さ（4つの相手を区別する）

商社の営業は「客には売る側」「メーカーには買う側」「スタッフには頼む側」「上司の言葉は通訳する側」を1日に何度も切り替える。**文ごとに相手を決めてから書く**。

| 相手 | 丁寧さ | 依頼の型 | 語の選び方 | 呼び方 |
|---|---|---|---|---|
| 客（ลูกค้า） | 高 | ขอ…／รบกวน…／ช่วย…ได้ไหมครับ | แจ้ง（伝える）・สินค้า（商品）・ตรวจสอบ（確認・改まった場） | ลูกค้า、または呼びかけ無し |
| メーカー・仕入先担当（タイ人） | 中〜高（買う側なので少し押せる） | ขอสอบถาม…／รบกวนช่วยเร่ง…ให้หน่อยนะครับ | เช็ค／ตรวจสอบ どちらも可 | ทางผู้ผลิต／ทางโรงงาน |
| 社内スタッフ（タイ人） | 中（丁寧だが指示として通る） | ช่วย…ด้วยนะครับ／ช่วย…หน่อยได้ไหมครับ／ฝาก…ด้วยนะครับ | เช็ค・ส่ง・บอก・ของ（もの） | 呼びかけ無し（§2.2 末尾） |
| 上司（日本人）の言葉を通訳 | 中立・正確 | หัวหน้าบอกว่า…／ฝากบอกว่า…／อยากให้… | 自分の意見を混ぜない | หัวหน้า／ผู้จัดการ／ทางญี่ปุ่น |

**客（ลูกค้า）に言う文**
- 全文 ครับ。依頼は ขอ〜／รบกวน〜／ช่วย〜ได้ไหมครับ。自社は ทางเรา／บริษัทเรา。
- 質問の前置き ไม่ทราบว่า…（ไม่ทราบว่าสะดวกวันไหนครับ＝ご都合はいつがよろしいですか）。
- 断言を避ける：ประมาณ（約）／น่าจะ（〜のはず）／คาดว่า（〜見込み）。納期は「約」で言う。ประมาณ を落とすと納期の断定になる。
- 禁止：裸の命令形、客に義務を言う ต้อง、เอา（→ ต้องการ／รับ）、ไม่รู้（→ ไม่แน่ใจ／ไม่ทราบ）、ไม่ได้ の一言で断る（→ ตรงนี้อาจจะทำให้ไม่ได้ครับ ＋代案）。
- 客に ช่วย…หน่อย（友達に頼む響き）／ของ／บอก は軽い → รบกวน…นะครับ／สินค้า／แจ้ง。
- 不良は客には สินค้าที่มีปัญหา（問題のある品）、社内・メーカーには ของเสีย／งาน NG。

**社内スタッフに言う文**
- 依頼の強さを4段で固定。S02 の既定は②。

| 段 | 形 | いつ |
|---|---|---|
| ① | ช่วย…หน่อยครับ／ช่วย…หน่อยได้ไหมครับ | 軽い頼み（ช่วยดูหน่อยครับ＝ちょっと見て） |
| ② | ช่วย…ด้วยนะครับ | 標準の指示・依頼 |
| ②' | ฝาก…ด้วยนะครับ | 「預ける」ニュアンス。自分が席を外す・後でやってよい依頼（ฝากแก้เอกสารตัวนี้ด้วยนะครับ＝この資料、直しておいて） |
| ③ | รบกวน…ด้วยครับ | 手間をかける・急ぎ（รบกวนส่งวันนี้ด้วยครับ＝お手数ですが今日中に） |
| ④ | ต้อง…นะครับ ＋理由 | 上司・日本側の締切を伝えるときだけ |

- กรุณา／โปรด は貼り紙・書面の語なので会話に出さない（口で言うと嫌味に聞こえる）。ห้าม は安全ルール以外で使わない。
- 急かすときは เร็วๆ 単独にしない → ถ้าเป็นไปได้ ขอวันนี้นะครับ（できれば今日中にお願いします）。
- 「〜しといて」の軽さを重大指示に格上げしない（ต้อง は本当に必須のときだけ）。
- 呼びかけ พี่／น้อง は使わない（年齢・上下で変わり、教材に固定できない）。役職語（หัวหน้า／คนดูแล／ลูกค้า）で言い、名前がどうしても要るときだけ `th`＝คุณ A、`th_tts`＝คุณเอ、`reading`＝クン エー（実在しそうな名前は禁止）。

**上司の言葉を通訳する文**
- 前置きを固定：หัวหน้าบอกว่า…（上司が言うには）／หัวหน้าฝากบอกว่า…（上司から〜と伝えてほしいとのこと＝伝言の依頼）／ทางญี่ปุ่นขอให้…（日本側は〜してほしいと）／ผู้จัดการอยากให้…（部長は〜してほしい）。
- พูดว่า（単に発話した）と บอกว่า／ฝากบอกว่า（伝聞・伝言）を区別する。ตามที่…กล่าวว่า は書き言葉。เขาว่า は雑。
- 自分の意見・推量（คงจะ／น่าจะ）を混ぜない。締切・数量・条件は落とさない。
- 「ญี่ปุ่นบอกว่าต้อง…」と日本側を怖く見せない。หัวหน้าอยากให้… で意図を伝える。

### 2.3 避ける表現（置換表）

| 避ける | 理由 | 代わりに |
|---|---|---|
| ท่าน／กระผม／ขอรับ | 王室語・過剰敬語 | คุณ／ผม／ครับ |
| กรุณา／โปรด | 書き言葉・張り紙調 | ช่วย／รบกวน／ขอ |
| จึง／ทั้งนี้／ดังกล่าว／ณ／ซึ่ง／ทำการ＋動詞／ดำเนินการ | 書面語（ดำเนินการ は S10 の書面文脈のみ可） | 口語に言い換える（ซึ่ง → ที่） |
| ต้อง…（客・スタッフへ） | 命令に聞こえる | ช่วย…ด้วยนะครับ／รบกวน… |
| ไม่ได้ครับ（きっぱり否定） | 営業は言い切らない | อาจจะไม่ทันครับ／คงยากครับ／ขอเช็คก่อนนะครับ ＋代案 |
| เข้าใจไหม | 「分かった？」は上から | โอเคไหมครับ／ชัดเจนไหมครับ |
| อะไรนะ | 「は？」に近い | ขอโทษครับ ยังไงนะครับ（すみません、何とおっしゃいました？） |
| ผิด／ความผิดของ…（責任の断定） | 商社は原因確定前に責任を言わない | ไม่ตรงกับสเปค／มีปัญหา／ขอตรวจสอบก่อน |
| ราคาถูก（安い） | 「安物」の響き | ราคาพิเศษ／ลดให้ได้…เปอร์เซ็นต์ |
| แปลว่า…（「つまり」の意味で） | แปลว่า は語義。意図の言い換えには不適 | หมายความว่า…／ก็คือ… |
| ถูก…（受身の多用） | 翻訳調 | 能動で言う |
| ผมคิดว่า…（毎回付ける） | 「〜と思います」の直訳癖 | น่าจะ／คงจะ を動詞の前に |
| ขออนุญาต…（毎回付ける） | 「〜させていただきます」の直訳癖 | ขอ＋動詞 |
| เหนื่อยไหม（お疲れ様の直訳） | 「疲れた？」と聞いている | §2.6 の場面別 |
| ฝากเนื้อฝากตัว（よろしくの直訳） | 大げさ | ฝากด้วยนะครับ／ยินดีที่ได้รู้จักครับ |
| 24時間表記の読み（สิบห้านาฬิกา） | 話し言葉では使わない | บ่ายสามโมง（§5.2） |

- 曖昧語「大丈夫です」は ได้ครับ（OK）か ไม่เป็นไรครับ（気にしないで）のどちらかに決めてから訳す。
- 前職の工場用語をそのまま持ち込まない。商社の立場は「間に立って調整する」なので、ทางเราจะประสานกับผู้ผลิตให้ครับ（弊社がメーカーと調整します）のような言い方を基本にする。

### 2.4 外来語・略語

- 原則：タイ人社員が口で言う形が外来語なら、**タイ文字の外来語**で書く。書面語として固有語が定着しているものは固有語。客向けにタイ語本来の語がある時は note に併記する。
- `th` に英字を残してよいのは、学習者が目で認識すべき略語だけ（PO／NG／OK／QC／MOQ／VAT／mm／kg）。大文字・ピリオドなし。その場合も `th_tts` はタイ文字に置換（§5.3）。略語は1セットに3種まで（多いと「英語で言えばいい」教材になる）。
- 型番・ブランド名・メーカー名は書かない → รุ่นนี้（この型番）／รหัสนี้／ผู้ผลิตรายนี้（このメーカー）で代用。英数字の型番は架空でも書かない。

| 日本語 | th（表示） | 別形（客向け・書面） | th_tts | 備考 |
|---|---|---|---|---|
| 確認する | เช็ค | ตรวจสอบ | เช็ค | 会話の既定。品質検査・改まった場は ตรวจสอบ |

### 2.5 日本語側の書き方（キューは「本当に聞こえる日本語」）

`jp` は学習者が**最初に聞く合図**。ここが教科書調だと、実際に上司が言ったときに反応できない。

- 日本人上司・営業が実際に口にする自然な話し言葉。です・ます体で「。」で終える（S04 の数字句は「。」なし）。乱暴な口調（「〜しろ」）は入れない。
- 長さ：Level 1〜2 は30字以内、Level 3 は40字以内（3秒間、頭に保持できる長さ）。
- **タイ語訳が一意に決まる言い方にする**：「確認します」だけでは在庫か納期か分からない → 「在庫を確認して折り返します」。目的語・期限を入れる。相手が要る文は語彙で示す（「お客様に」「部長が言うには」「日本側は〜だそうです」）。
- 括弧の注記は使わない（TTS が読む・チャプター名が崩れる）。inbox に「（スタッフに）」のようなメモがあっても `jp` には入れず、訳の相手決めにだけ使う。
- 同じセット内で「〜してください」を5回以上並べない。「〜お願いできますか」「〜しておいて」「〜してもらえますか」を混ぜる。
- TTS 対策：「〜」「/」「（）」「%」「mm」「kg」「15:30」を書かない。→「から」「または」、パーセント、ミリ、キロ、15時半。「1日」は「月初」で回避（ついたち／いちにち が揺れる）。数字は算用数字で可（1,500個、25,000バーツ）。
- 実名・実価格・実型番を入れない。会社＝うち／弊社、客＝お客様、上司＝部長／課長／上司、製造元＝メーカー／日本側、人＝Aさん。

## 3. Level 1〜3 の判定基準

判定は**タイ語側**で行う（日本語の長さでは判定しない）。level は難易度であると同時に学習の優先順（1＝まずこれ、2＝次、3＝余裕があれば）。

**音節の数え方**：発音上の音節を数える（ครับ＝1、สัปดาห์＝2、ใบเสนอราคา＝5、อาทิตย์＝3、มาตรการ＝3）。ครับ／นะครับ も数に入れる。

Level は「長さ」と「構造」の**高い方**：

| | Level 1 | Level 2 | Level 3 |
|---|---|---|---|
| 音節 | 10以下 | 11〜16 | 17〜22（23以上は2文に割る） |
| 構造 | 骨格1本＋差し替え1つ。接続なし | 骨格＋追加1つ（接続 แล้ว／ก่อน／ถ้า／เพราะ／หลังจาก、期限、数字、専門名詞のどれか1つ） | 2節（条件・理由・伝聞）または追加2つ以上、または日本語の婉曲を置き換える文 |
| 新語 | 0〜1 | 1〜2 | 2〜3 |
| 数字 | なし〜2桁 | 1つ | 2つ以上、または万単位・小数 |
| 日本語 | 30字以内 | 30字以内 | 40字以内 |

追加ルール：
- 丸ごと覚える定型（เดี๋ยว…แล้วจะ…กลับ、ขอ…ก่อนนะครับ）は「骨格1本」と数える。
- 通訳の前置き（หัวหน้าบอกว่า…）が付いた文は、中身が Level 1 なら 2、中身が 2 なら 3。
- 万単位以上の金額、時刻の บ่าย／ทุ่ม 換算、日付＋月名を含む文は最低 Level 2。
- 音節上限を超えたら Level を上げるのではなく**文を短くする**（Level 3 でも 22 音節を超えない。自然速度で6秒以内）。
- S04 の数字句は語数に関係なく、3桁以下＝1、4桁以上・万単位・小数・時刻・日付＝2（句に Level 3 は無い）。

例：
- ขอเช็คก่อนนะครับ（確認しますね）＝5音節・骨格のみ → **1**
- หัวหน้าบอกว่าอยากเริ่มตั้งแต่อาทิตย์หน้าครับ（上司が言うには来週から始めたいそうです）＝12音節・伝聞1つ → **2**
- มาตรการชั่วคราว ขอให้ตรวจสอบทั้งหมดก่อนนะครับ（暫定対策として全数検査をお願いします）＝14音節だが専門名詞＋依頼の2節 → **3**
- สินค้าตัวนี้ใช้เวลาส่งมอบประมาณสี่สัปดาห์หลังจากสั่งซื้อครับ（この製品の納期は注文から約4週間です）＝19音節 → **3**。既存 daily では 1 になっているが、この基準では 3

## 4. カタカナ読み（`reading`）の規則

カタカナは**記憶の補助**であり発音の正典ではない（正典は音声）。だから「一貫していて一目で読める」ことを優先し、声調記号は付けない。同一セット内で揺らさないことが最優先。

### 4.1 基本
- 単位は**語**：1語＝1トークン、複合語は1トークン（ใบเสนอราคา＝バイサヌーラーカー、ส่งมอบ＝ソンモープ、ติดต่อ＝ティットー、กำหนดส่ง＝ガムノットソン）、語の間は半角スペース。ครับ は必ず独立（クラップ）。นะครับ は「ナ クラップ」。
- 使える文字：カタカナ・小書き（ァィゥェォャュョッ）・ー・半角スペースのみ。「・」「-」「ヴ」「、」「。」は使わない（「、」「。」は `check` で落ちる）。タイ語側のスペース（節の切れ目）は読みでもスペース1つ。
- 声調記号・アクセント記号は付けない。同音のカナ（ไม่＝ไหม＝マイ）は区別しない。
- 数字はカナで読みを書く（1,500 → ヌンパンハーローイ）。算用数字を書かない。英字略語はタイ式（PO → ピーオー、QC → キウシー、NG → エンジー）。
- ๆ は語を繰り返す（ช้าๆ → チャーチャー）。
- 外来語は**タイ人の発音で書く**（日本語の外来語に引きずられない）：อีเมล → イーメーン、สต็อก → サトック、คอนเฟิร์ม → コーンフーム、ออเดอร์ → オーダー、ลีดไทม์ → リートタイ、แวต → ウェット。
- 長さの目安：`jp` の3倍を超えたら文を分ける合図。

### 4.2 長母音（綴りで機械的に決める。発音の微妙な長短で迷わない）
- **ー を付ける**：า ี ื ู เ- แ- โ- -อ เ-อ เ-ิ（例 ราคา ラーカー、ซื้อ スー、ขอ コー、เธอ トゥー、เริ่ม ルーム）
- **ー を付けない**：ะ ิ ึ ุ เ-ะ แ-ะ โ-ะ เ-าะ -ั ไ ใ เ-า -ำ と暗黙母音（例 ผม ポム、คน コン、ไป パイ、เก้า ガオ、ก็ ゴ、ทำ タム）
- 二重母音は ー なし：เ-ีย → イア（เดี๋ยว ディアオ、เรียน リアン、เปลี่ยน プリアン、เสีย シア）、เ-ือ → ウア（เดือน ドゥアン、เรื่อง ルアン）、-ัว／-ว- → ウア（ตัว トゥア、ช่วย チュアイ、ด้วย ドゥアイ）
- 母音の統合（区別しない）：เอ＝แอ → エ段、โอ＝ออ → オ段、เออ＝อือ → ウ段（เริ่ม ルーム、มือ ムー、คือ クー、เสนอ サヌー）
- 例：ใบเสนอราคา → バイサヌーラーカー（ใบ バイ／เสนอ サヌー／ราคา ラーカー）

### 4.3 有気音・無気音の書き分け（決定事項）

| タイ文字 | 種類 | カナ | 例 |
|---|---|---|---|
| ก | 無気 | **ガ行** | ก่อน ゴーン、กลับ グラップ、กำหนด ガムノット、เก็บ ゲップ、แก้ ゲー |
| ข ค ฆ | 有気 | カ行 | ขอ コー、ครับ クラップ、ค่า カー |
| จ | 無気 | **ジャ行** | จะ ジャ、จัด ジャット、แจ้ง ジェーン、จุด ジュット |
| ฉ ช ฌ | 有気 | チャ行 | ช่วย チュアイ、เช็ค チェック |
| ด ฎ | 有声 | ダ行 | ได้ ダイ、เดือน ドゥアン |
| ต ฏ | 無気 | タ行 | ตัว トゥア、ต่อ トー、ตรวจ トゥルアット |
| ถ ท ธ ฐ ฑ ฒ | 有気 | タ行（ต と同じ） | ถ้า ター、ทำ タム |
| บ | 有声 | バ行 | บอก ボーク、ใบ バイ |
| ป | 無気 | パ行 | ไป パイ、ประมาณ プラマーン |
| ผ พ ภ | 有気 | パ行（ป と同じ） | ผม ポム、พรุ่งนี้ プルンニー |
| ง（頭） | — | ンガ行 | งาน ンガーン、เงิน ングン |

- 理由：日本語のカナで書き分けられるのは ก／ค（と จ／ช）の対だけ。ก→ガ行は日本人が既に知っている食べ物表記（ガイヤーン・ガパオ・ゲーン）と同じで、無気音を「濁音寄り」で出す癖がつく。タイ語に g 音は無いのでガ行は衝突しない。ต／ท と ป／พ は書き分けを諦め（ダ行・バ行は ด／บ と衝突する）、音声で覚える。混同が致命的な語（ต้อง など）は note で触れてよい。
- 既存 daily の กลับ＝クラップ、ภายใน＝パイナイ はこの規則では**グラップ、パーイナイ**。以後はこの規則に統一し、既存文は次に触るときに直す。
- そのほか：ร ล ฬ → ラ行（区別しない）、ว → ワ／ウィ／ウェ／ウォ（ว่า ワー、เวลา ウェーラー、วัน ワン）、ย ญ → ヤ行（อยู่ ユー、ญี่ปุ่น イープン）、ห ฮ → ハ行、ฟ ฝ → ファ行、ส ศ ษ ซ → サ行、ห นำ／อ นำ は無視（หน่อย ノーイ、อยาก ヤーク、ไหม マイ）、ทร → サ行（ทราบ サープ）。

### 4.4 子音の連続
- 真の二重子音（กร คร ปร พร ตร กล คล ปล พล กว คว）：**1字目をウ段**＋2字目に母音（ครับ クラップ、ปลา プラー、ตรวจ トゥルアット、ประชุม プラチュム、ความ クワーム、รบกวน ロップグアン）。
- 母音字のない連続子音（สนอ／สบาย／ถนน／สเปค／สต็อก／ผลิต）：発音どおり**「ア」を挿入**（เสนอ サヌー、สบาย サバーイ、สเปค サペック、สต็อก サトック、ผลิต パリット、ขนาด カナート）。

### 4.5 末子音
- -n（น ณ ญ ร ล ฬ）／-ng（ง） → ン（区別しない。อีเมล イーメーン、บิล ビン）。-m → ム。
- 末子音 k／t／p（ก ข ค／ด ต ถ ท จ ช ส ศ ษ ฎ ฏ ธ／บ ป พ ฟ ภ）：
  - **短母音のあと → ッ＋ク／ト／プ**：ครับ クラップ、เช็ค チェック、ติด ティット、หก ホック、สิบ シップ、เจ็ด ジェット
  - **長母音・二重母音のあと → ク／ト／プ（ッなし）**：มอบ モープ、มาก マーク、แปด ペート、ทราบ サープ、ตรวจ トゥルアット
  - 語中で促音末子音の直後に**同系統の子音**が続くときは「ッ」だけ（ติดต่อ ティットー、สวัสดี サワッディー、รับผิดชอบ ラッピットチョープ）。別系統なら ット＋次の語（กำหนดส่ง ガムノットソン、ทั้งหมด タンモット）。
- -y／-w は母音で処理：ไ ใ → アイ、-าย → アーイ（ภายใน パーイナイ）、-อย → オーイ（ร้อย ローイ、หน่อย ノーイ）、เ-า → アオ、-าว → アーオ、แ-ว → エーオ（แล้ว レーオ）、เ-ย → ウーイ（เลย ルーイ）、-ิว → イウ、เ-็ว → エオ（เร็ว レオ）。
- การันต์（์ の付いた字）は無音：ไลน์ ライ、เปอร์เซ็นต์ プーセン、สัปดาห์ サップダー、อาทิตย์ アーティット、วันศุกร์ ワンスック、ลีดไทม์ リートタイ。

### 4.6 数字・時間の読み（S04 で多用。固定）

## 5. `th_tts` の規則（edge-tts th-TH-NiwatNeural 向け読み上げ専用テキスト）

原則：**タイ文字・スペース・ๆ だけ**。`check` の正規表現は英字・数字・()[]・引用符を弾く。それ以外の記号（, . / - : ; ! ? % ฿ ฯ タイ数字 ๐〜๙）も TTS の読みが不安定なので**すべて語に置き換えるか削除する**。

### 5.1 数字
- 数はタイ語の語で書く：1,500 → หนึ่งพันห้าร้อย、11 → สิบเอ็ด、21 → ยี่สิบเอ็ด（「1」は เอ็ด）、20 → ยี่สิบ（สองสิบ にしない）、100 → หนึ่งร้อย、1,000 → หนึ่งพัน。
- 万単位は換算する：1万 → หนึ่งหมื่น、10万 → หนึ่งแสน、100万 → หนึ่งล้าน、1,000万 → สิบล้าน、25万バーツ → สองแสนห้าหมื่นบาท、35万バーツ → สามแสนห้าหมื่นบาท。日本の「万」単位をそのまま持ち込まない。
- 小数：2.5 → สองจุดห้า、0.5 → ศูนย์จุดห้า。公差 ±0.1 → บวกลบศูนย์จุดหนึ่ง。
- パーセント：10% → สิบเปอร์เซ็นต์。7割 → เจ็ดสิบเปอร์เซ็นต์。
- 単位は正式形を既定に：mm → มิลลิเมตร、kg → กิโลกรัม、個 → ชิ้น、台 → ตัว／เครื่อง、セット → ชุด、箱 → กล่อง、ケース → ลัง、リール → ม้วน、本（ケーブル） → เส้น、枚（書類） → ใบ、明細行 → รายการ、回・便 → ครั้ง、ロット → ล็อต、1個あたり → ชิ้นละ…／ต่อชิ้น。口語の短縮（มิล、โล）は note で触れる。
- 口語の数字（พันห้า＝1,500、ร้อยนึง＝100）は `th_tts` に使わず、note に「口語は พันห้า」と書く。

### 5.2 日付・時刻・期間
- 日付：15日 → วันที่สิบห้า、来月15日 → วันที่สิบห้าเดือนหน้า、月末 → สิ้นเดือน、月初 → ต้นเดือน。
- 月名は正式形（ตุลาคม）を既定にする（TTS が確実に読む。`th` も ต.ค. の省略形にしない）。会話の短縮形（ตุลา）は note で触れる。
- 曜日：วันจันทร์…วันศุกร์。「金曜までに」 → ภายในวันศุกร์。
- 時刻は会話体系で書く：9:00 เก้าโมงเช้า、10:00 สิบโมง、10:30 สิบโมงครึ่ง、12:00 เที่ยง、13:00 บ่ายโมง（บ่ายหนึ่งโมง とは言わない）、14:00 บ่ายสองโมง、14:30 บ่ายสองครึ่ง、15:00 บ่ายสามโมง、16:00 สี่โมงเย็น、17:00 ห้าโมงเย็น、18:00 หกโมงเย็น、19:00 หนึ่งทุ่ม。24時間制（สิบสี่นาฬิกา）は使わない。
- 期間：3日 สามวัน、2週間 สองสัปดาห์、1か月 หนึ่งเดือน、半月 ครึ่งเดือน、1週間半 อาทิตย์ครึ่ง。「〜以内」 ภายใน、「〜まで」 ก่อน／ภายใน、「〜以降」 หลังจาก、「〜から〜まで」 ตั้งแต่…ถึง…。
- 年は文に入れない。

### 5.3 略語・英字・記号
- 略語はタイ文字で音写：PO → พีโอ、NG → เอ็นจี、OK → โอเค、QC → คิวซี、MOQ → เอ็มโอคิว（ただし文では ขั้นต่ำ を使う）、VAT → แวต、PDF → พีดีเอฟ、Excel → เอ็กเซล、LINE → ไลน์、email → อีเมล。
- 人名の記号：คุณ A → คุณเอ。会社：บริษัท A → บริษัทเอ。
- 記号：% → เปอร์เซ็นต์、. → จุด、/ → ต่อ（単価 ต่อชิ้น）、〜（範囲） → ถึง、: → 時刻語で書き直す。「?」「!」「,」「"」「-」「( )」は削除（疑問は ไหม／หรือเปล่า が担う）。
- 引用が要る文（S09）は語を引用しない。คำนี้（この語）／ประโยคนี้（この文）／ที่หัวหน้าพูด（上司が言ったこと）で指す。日本語の語を `th_tts` に入れると Niwat が崩れる。
- タイ数字（๑๒๓）・ฯลฯ・ฯ・省略記号（บ.／จ.／น.）は使わず全形で書く。ๆ は使ってよい。生成後に聴いて繰り返されていなければ、その文だけ `th_tts` で語を2回書く（ช้า ช้า）。`th` は ๆ のまま。

### 5.4 分かち書き
- `th` と同じ位置にスペース（節の切れ目）。スペース＝短いポーズなので、แล้ว／แต่／ถ้า の前、ก่อน の後に1つ入れると読みが自然になる。単語ごとに入れない（切りすぎると棒読みになる）。
- ครับ／นะครับ は前の語に付ける（แจ้งกลับนะครับ）。
- TTS が語を誤って切る（同綴異読）ときだけ、`th_tts` の語境界にスペースを1つ足して直す。`th` は触らない。`--dry` では分からないので、生成後に該当文だけ聴いて確認する。
- 読みが怪しい語（หัก ณ ที่จ่าย、เปอร์เซ็นต์、ล็อต、แวต、外来語全般）は note に書かず、**要検証の id 一覧を別に提出**する。読めなければその語を含む文はセットから外す。

## 6. `note` の書き方（目標40字・上限60字）

**役割**：「なぜその言い方か」を1点だけ。訳の言い直しではない。

**型**（この順・体言止め・「。」で区切り最大2文）
`骨格または語＝日本語の意味。理由 or 使い分け or 落とし穴`

**書いてよい5種類（1つ選ぶ）**

| 型 | 書き方 | 例（字数） |
|---|---|---|
| 1 骨格＋差し替え | 「〜の型。〜を差し替え」 | เดี๋ยว〜ก่อน＝「まず〜してから」。折り返しの定番（29） |
| 2 語の選択理由・対比 | 「AでなくB。Aは〜」 | ตรวจสอบでなくเช็ค。電話では口語が自然（24） |
| 3 相手による使い分け | 「客には〇〇、社内は△△」 | 客には รบกวน、社内は ช่วย…หน่อย（24） |
| 4 落とし穴・意図 | 「〜だと〇〇に聞こえる。△△で和らぐ」 | ต้องだと命令調。ช่วยで依頼になる（20） |
| 5 数字の読み・桁 | 「〜＝口語は〜」「〜の桁に注意」 | 25万＝สองแสนห้าหมื่น。万をそのまま使わない（29） |

**禁止**
- 文全体の直訳・言い直し（`jp` の繰り返し）
- 文法用語（使役・複合動詞・類別詞・副詞・接続詞 など）。「〜の型」「〜の語」で言う
- 「丁寧な表現です」「よく使います」（なぜ・いつが無い）
- 2つ以上の論点、です・ます、声調記号、実名
- タイ語を2語以上並べる（文字数がすぐ超える。Python の `len` で母音記号も1字）。代替表現を載せるなら1つまで、「〜も可」で終える

**例**
- 良：ขั้นต่ำ＝下限。MOQ はこの一語で通じる（24字）
- 良：納期＝期間ならใช้เวลา、日付ならกำหนดส่ง（27字）
- 良：ประมาณ を落とすと納期の断定になる（20字）
- 良：แปลว่า は語義。意図の言い換えは หมายความว่า（31字）
- 悪：この文は「確認して後で連絡します」という意味で、客先でよく使います（言い直し・40字超）
- 悪：เดี๋ยว は副詞で、ก่อน は「先に」を表す接続詞（文法用語・2論点）

## 7. セット別の指示

各セットに「ねらい／使う骨格／必ず入れる一言（そのまま採用してよい叩き台）／その他候補／避けるズレ／title」。例のタイ語には日本語訳を付けてある。文数と Level 配分は §3 の表に従う。「必ず入れる一言」を先に置き、骨格ごとの差し替え版で目標文数まで埋める。

### S01（15文）通訳の繋ぎ言葉 — title「通訳の繋ぎ」／title_th「คำเชื่อมตอนแปล」
- ねらい：通訳の場で**口が止まらない**ための定型。両方向とは「①上司の日本語をタイ人に渡す前置き」と「②タイ人の発言を受け取るときの確認・聞き返し・日本側へ伝える断り」。どちらもタイ語で言う文。上司に日本語で言う側は母語なので作らない。②は最低4文。
- 骨格：#5 #6 #10 #2。
- 必ず入れる一言：
  1. 部長が言うには、来週から始めたいそうです。→ หัวหน้าบอกว่าอยากเริ่มตั้งแต่อาทิตย์หน้าครับ
  2. すみません、もう一度お願いします。→ ขอโทษครับ ช่วยพูดอีกครั้งได้ไหมครับ（すみません、もう一度言ってもらえますか）
  3. 確認しますね。→ ขอเช็คก่อนนะครับ
  4. つまり、今週は出荷できないということですね。→ สรุปคืออาทิตย์นี้ส่งของไม่ได้ใช่ไหมครับ
  5. 少々お待ちください、今訳します。→ รอสักครู่นะครับ เดี๋ยวผมแปลให้ครับ
  6. 言い方を変えると、こういうことです。→ พูดอีกอย่างก็คือแบบนี้ครับ（別の言い方をするとこうです）
  7. ゆっくり話してもらえますか。→ ช่วยพูดช้าๆ หน่อยได้ไหมครับ
  8. 今の話、私から上司に伝えますね。→ เดี๋ยวผมแจ้งหัวหน้าให้นะครับ（後で私が上司に伝えますね）
- その他候補：私の理解で合っていますか → ผมเข้าใจถูกไหมครับ／先に要点だけまとめますね → ขอสรุปประเด็นหลักก่อนนะครับ／日本側に確認してから答えます → ขอเช็คกับทางญี่ปุ่นก่อนแล้วจะตอบนะครับ／その言葉の意味を教えてもらえますか → ช่วยอธิบายคำนี้หน่อยได้ไหมครับ。
- 避けるズレ：一般会話の聞き返し（อะไรนะ）に流れない／ล่าม（通訳者）の改まった言い回し（ขออนุญาตแปล…）にしない／上司の意見に自分の推量を混ぜない／「〜でよろしいですか」は ใช่ไหมครับ（念押し）と ได้ไหมครับ（可否）を混ぜない／「〜が言うには」を ตามที่…กล่าว にしない（บอกว่า）／つまり＝แปลว่า にしない（สรุปคือ／หมายความว่า／ก็คือ）／繋ぎ言葉だけの断片（หัวหน้าบอกว่า… で終わる文）を作らない。必ず中身付きの完全文にする。

### S02（15文）指示・依頼（上司→スタッフ） — title「指示と依頼」／「การสั่งงาน」
- ねらい：丁寧だが指示として通る言い方。通訳形（หัวหน้าอยากให้…／ทางญี่ปุ่นขอให้…）と自分形（ช่วย…ด้วยนะครับ）を**同じ内容で対にして**入れる（「立場で前置きが変わるだけ」と気づかせる）。締切・送付・確認・報告・準備・修正・優先順位・共有の8機能を網羅。
- 骨格：#1 #3 #5 #7。依頼の強さは §2.2 の4段（＋②'）を全部1回以上出す。
- 必ず入れる一言：
  1. 明日の午前中までに見積書を送ってください。→ ช่วยส่งใบเสนอราคาภายในเช้าพรุ่งนี้ด้วยนะครับ
  2. 部長が、今日中に報告書がほしいそうです。→ หัวหน้าอยากได้รายงานภายในวันนี้ครับ
  3. こっちを先にやってください。→ ช่วยทำอันนี้ก่อนนะครับ
  4. 終わったら教えてください。→ เสร็จแล้วบอกผมด้วยนะครับ
  5. この資料、間違いがあるので直してください。→ เอกสารนี้มีที่ผิดอยู่ ช่วยแก้ด้วยนะครับ
  6. お客様に確認して、結果を私に報告してください。→ ช่วยเช็คกับลูกค้า แล้วรายงานผมด้วยครับ
  7. 急ぎではないですが、今週中にお願いします。→ ไม่รีบมากครับ แต่ขอภายในอาทิตย์นี้นะครับ
  8. 日本側が、金曜までに返事がほしいと言っています。→ ทางญี่ปุ่นขอคำตอบภายในวันศุกร์ครับ
- その他候補：送る前にもう一度確認してください → ก่อนส่งช่วยเช็คอีกรอบนะครับ／みんなに共有しておいてください → ช่วยแชร์ให้ทุกคนด้วยนะครับ／会議の前に資料を準備しておいてください → ช่วยเตรียมเอกสารไว้ก่อนประชุมนะครับ／メーカーに納期を聞いてもらえますか → ช่วยถามกำหนดส่งกับผู้ผลิตให้หน่อยได้ไหมครับ／この資料、直しておいてもらえますか → ฝากแก้เอกสารตัวนี้ด้วยนะครับ。
- 避けるズレ：命令形（ส่งมา！）や กรุณา／โปรด／ต้อง の乱用／締切のない依頼（指示として通らない）／目的語のない指示（何を・誰に・いつまでに、のうち2つ以上を入れる）／「〜までに」を จนถึง にしない（ภายใน）。「〜の前に」は ก่อน、「間に合うように」は ให้ทัน／「共有して」を แชร์ 以外（เผยแพร่ など書き言葉）にしない。

### S03（15文）客先への説明（納期・見積・在庫・価格） — title「客先への説明」／「อธิบายให้ลูกค้า」
- ねらい：営業がタイ人客に言う定型。**即答しない・でも放置しない**。断言せず「約」「確認して折り返す」で守る言い方を体に入れる。納期回答／見積送付／在庫確認／価格説明／代替品提案／最小ロット／支払条件／折り返し。
- 骨格：#2 #4 #7 #8 #9 #12。
- 必ず入れる一言：
  1. 納期は、ご注文後およそ4週間です。→ ส่งมอบประมาณสี่สัปดาห์หลังสั่งซื้อครับ
  2. 在庫を確認して折り返します。→ เดี๋ยวเช็คสต็อกแล้วแจ้งกลับนะครับ
  3. 見積書は今日中にお送りします。→ ใบเสนอราคาจะส่งให้ภายในวันนี้ครับ
  4. この型番は生産終了なので、代替品をご提案します。→ รุ่นนี้เลิกผลิตแล้ว ผมขอเสนอตัวทดแทนนะครับ
  5. 価格は数量によって変わります。→ ราคาขึ้นอยู่กับจำนวนครับ
  6. 最小ロットは100個です。→ สั่งขั้นต่ำหนึ่งร้อยชิ้นครับ
  7. 支払条件は30日後の後払いです。→ เงื่อนไขชำระเงินคือเครดิตสามสิบวันครับ
  8. メーカーに確認してからお返事します。→ ขอเช็คกับทางผู้ผลิตก่อน แล้วจะแจ้งนะครับ
- その他候補：この価格は VAT 別です → ราคานี้ยังไม่รวมแวตครับ／分納も可能です → แบ่งส่งได้ครับ／今の在庫なら来週出荷できます → ถ้าเป็นสต็อกที่มีอยู่ น่าจะส่งได้อาทิตย์หน้าครับ／この価格は今月末まで有効です → ราคานี้ใช้ได้ถึงสิ้นเดือนนี้ครับ。
- 避けるズレ：実価格・実社名（数字は「約」「例」の範囲で架空）／ยืนยัน（確約）・ได้แน่นอน／ทันแน่นอน を納期に使わない（น่าจะ／ประมาณ／คาดว่า）／納期（日付＝กำหนดส่ง）とリードタイム（期間＝ใช้เวลา）の混同／客に ต้อง／ไม่ได้ で言い切らない／客に ช่วย…หน่อย／ของ／บอก（→ รบกวน／สินค้า／แจ้ง）／「安くします」を ราคาถูก にしない（ลดให้／ราคาพิเศษ）／値引き交渉の文は入れない／メール文体（เรียนลูกค้า…）にしない。

### S04（20文）数字・日付・単位・時間ドリル — title「数字ドリル」／「ฝึกตัวเลข」
- ねらい：通訳で一番詰まる数字を**反射**にする。10文は数字句だけ（`jp` に「。」なし、`th` に ครับ なし）、10文は数字入りの短文。十・百・千・万・十万の桁を最低1回ずつ。「以内／以降／まで」（ภายใน／หลังจาก／ถึง）を数字とセットで出す。
- 骨格：#7 #8。数字句は「数＋単位」の形に統一。
- 必ず入れる一言（句）：
  1. 1,500個 → หนึ่งพันห้าร้อยชิ้น（note：口語は พันห้า）
  2. 5万バーツ → ห้าหมื่นบาท
  3. 10パーセント → สิบเปอร์เซ็นต์
  4. 0.5ミリ → ศูนย์จุดห้ามิลลิเมตร（note：口語は มิล）
  5. 3週間 → สามสัปดาห์（note：会話は สามอาทิตย์）
  6. 来月15日 → วันที่สิบห้าเดือนหน้า
  7. 午後2時半 → บ่ายสองครึ่ง
  8. 2.5キロ → สองจุดห้ากิโลกรัม
- 必ず入れる一言（短文）：
  9. 単価は1個120バーツです。→ ราคาต่อชิ้นหนึ่งร้อยยี่สิบบาทครับ
  10. 納期は来月末です。→ กำหนดส่งสิ้นเดือนหน้าครับ
  11. 合計で35万バーツになります。→ รวมทั้งหมดสามแสนห้าหมื่นบาทครับ
  12. 10時に打ち合わせです。→ ประชุมสิบโมงครับ
- その他候補：25万バーツ → สองแสนห้าหมื่นบาท／在庫は残り300個です → เหลือในสต็อกสามร้อยชิ้นครับ／2か月かかります → ใช้เวลาสองเดือนครับ／会議は午前10時からです → ประชุมเริ่มสิบโมงเช้าครับ。
- 数字の罠（起草者が必ず守る）：11／21 は สิบเอ็ด／ยี่สิบเอ็ด、20 は ยี่สิบ、13〜16時は บ่ายโมง／บ่ายสอง／บ่ายสาม／บ่ายสี่โมง、17〜18時は ห้าโมงเย็น／หกโมงเย็น、19時〜は ทุ่ม、12時は เที่ยง、半は ครึ่ง。
- 避けるズレ：長文にしない／万単位を換算し忘れない（10万＝แสน）／時刻の体系を混ぜない（会話体系のみ、นาฬิกา 不可）／単位を省かない／年を入れない／同じ桁の数ばかりにしない／数字句に ครับ を付けない（短文には付ける）／`th` は `1,500 ชิ้น` のように数字表示、`th_tts` は語。

### S05（15文）品質トラブル・不良対応 — title「品質トラブル対応」／「รับมือปัญหาคุณภาพ」
- ねらい：前職の強みを商社の立場で言い直す。原因を自分で断定せず、客とメーカーの**間に立つ**言い方（ทางเราจะ…ให้）を骨格にする。報告／写真・ロット特定／原因究明／暫定・恒久対策／検査／返品・交換／再発防止。
- 骨格：#1 #4 #9 #11。
- 必ず入れる一言：
  1. 不良品が3個見つかりました。→ เจอของเสียสามชิ้นครับ
  2. ロット番号を教えてください。→ ขอเลขล็อตด้วยครับ
  3. 写真を送ってもらえますか。→ ช่วยส่งรูปมาให้หน่อยได้ไหมครับ（note：客には รบกวน）
  4. メーカーに原因を確認します。→ ผมจะเช็คสาเหตุกับทางผู้ผลิตให้ครับ
  5. 暫定対策として、全数検査をお願いします。→ มาตรการชั่วคราว ขอให้ตรวจสอบทั้งหมดก่อนนะครับ
  6. 不良品は交換させていただきます。→ ของเสียทางเราจะเปลี่ยนให้ครับ
  7. 恒久対策は来週ご報告します。→ มาตรการถาวรจะรายงานอาทิตย์หน้าครับ
  8. 同じロットの在庫は、出荷を止めてください。→ ล็อตเดียวกันที่อยู่ในสต็อก ขอหยุดส่งไว้ก่อนนะครับ
- その他候補：再発防止策をメーカーに求めます → จะขอแนวทางป้องกันการเกิดซ้ำจากผู้ผลิตครับ／原因が分かり次第ご報告します → พอทราบสาเหตุแล้วจะแจ้งทันทีครับ／ご迷惑をおかけして申し訳ありません → ต้องขอโทษที่ทำให้ไม่สะดวกด้วยครับ／返品の手続きを進めます → เดี๋ยวจัดการเรื่องส่งคืนให้นะครับ。
- 避けるズレ：責任追及・自社の非の断定（ความผิดของ…）を使わない（→ ขอตรวจสอบก่อน）／プレス工程の専門語（金型・バリ等）や QC 内輪の略語に深入りしない（商社の語彙 มาตรการชั่วคราว／ถาวร／แนวทางแก้ไข／ป้องกันการเกิดซ้ำ で止める）／客に ต้อง で検査を命じない／客に ของเสีย／งาน NG を連発しない（客には สินค้าที่มีปัญหา）／「検査」を全部 ตรวจสอบ にしない（現物は ตรวจ／ตรวจงาน、書類や事実の確認は ตรวจสอบ／เช็ค）／謝罪は #11 の型で1回、過剰に繰り返さない。

### S06（12文）社内会議・進捗報告 — title「会議と進捗」／「รายงานความคืบหน้า」
- ねらい：「項目名＋คือ＋中身」の型（ปัญหาคือ…／ขั้นต่อไปคือ…）で短く報告する。進捗／課題／次のアクション／担当／期限／保留／決定事項／予定通り。
- 骨格：#7 #10。
- 必ず入れる一言：
  1. 進捗は7割くらいです。→ คืบหน้าประมาณเจ็ดสิบเปอร์เซ็นต์ครับ
  2. 課題は、納期が遅れていることです。→ ปัญหาคือส่งมอบล่าช้าครับ
  3. 次のアクションは、メーカーへの確認です。→ ขั้นต่อไปคือเช็คกับผู้ผลิตครับ
  4. この件の担当は私です。→ เรื่องนี้ผมเป็นคนดูแลครับ
  5. 期限は金曜日です。→ กำหนดส่งคือวันศุกร์ครับ
  6. この件は一旦保留にします。→ เรื่องนี้ขอพักไว้ก่อนนะครับ
  7. 決まったことを共有します。→ ขอแจ้งข้อสรุปนะครับ
  8. 今日中に結論を出しましょう。→ วันนี้สรุปให้จบเลยนะครับ
- その他候補：スケジュールは予定通りです → ตอนนี้เป็นไปตามแผนครับ／特に問題ありません → ไม่มีปัญหาอะไรครับ／今週の進捗を報告します → ขออัปเดตความคืบหน้าของอาทิตย์นี้ครับ／まだ作業中です → กำลังทำอยู่ครับ。
- 避けるズレ：長い説明文にしない（1文1項目。進捗と課題を1文に入れない）／書き言葉の議事録調（ที่ประชุมมีมติ…）・会議用語の書き言葉化（วาระ／ประเด็น → เรื่อง）にしない／「まだ終わっていません」を ยังไม่เสร็จ で言い切らない（→ กำลังทำอยู่ครับ）／保留＝พักไว้ก่อน を ยกเลิก（中止）と混同しない／数字は割合と期限だけ。

### S07（12文）電話・チャットの口頭確認 — title「電話とチャット」／「โทรศัพท์และแชท」
- ねらい：LINE・電話で頻出の短い文。全部 Level 1〜2、10音節以内を目安。折り返し／担当者に代わる／送付確認／不在／伝言／都合の確認。
- 骨格：#4 #6 #12。
- 必ず入れる一言：
  1. 後で折り返します。→ เดี๋ยวโทรกลับนะครับ
  2. 担当者に代わります。→ เดี๋ยวโอนสายให้คนดูแลนะครับ（電話。対面・LINE なら เดี๋ยวให้คนดูแลคุยนะครับ）
  3. メール、届きましたか。→ ได้รับอีเมลหรือยังครับ
  4. 今、席を外しています。→ ตอนนี้ไม่อยู่ที่โต๊ะครับ
  5. 伝言をお願いできますか。→ ฝากข้อความได้ไหมครับ
  6. 今、お時間よろしいですか。→ ตอนนี้สะดวกคุยไหมครับ
  7. 資料を今送りました。→ ส่งเอกสารไปแล้วนะครับ
  8. 5分後にかけ直します。→ อีกห้านาทีโทรกลับนะครับ
- その他候補：伝えておきます → เดี๋ยวผมแจ้งให้นะครับ／LINE で送りますね → เดี๋ยวส่งทางไลน์นะครับ／営業部の者です → สวัสดีครับ ผมโทรจากฝ่ายขายครับ（社名を入れない名乗り）。
- 避けるズレ：メール文体の定型（เรียน／ด้วยความเคารพ）・書き言葉の電話マナー（ขออนุญาตเรียนสาย…）／電話の受け答え（สวัสดีครับ บริษัท…）に社名・自分の名前を入れない（ฝ่ายขาย で止める）／「伝言をお願いします」（ฝากบอก…）と「伝えておきます」（เดี๋ยวแจ้งให้）の混同／1文に2つの用件を入れない。

### S08（15文）職場の日常会話・クッション言葉 — title「職場の日常会話」／「บทสนทนาในที่ทำงาน」
- ねらい：人間関係を作る定型。直訳できない日本語（お疲れ様・よろしく）は §2.6 の対応で。挨拶／ちょっといいですか／手伝って／お礼／謝罪／急かす緩衝／昼食・帰り。
- 骨格：#3 #11 と、単独の挨拶定型。
- 必ず入れる一言：
  1. おはようございます。→ สวัสดีครับ（อรุณสวัสดิ์ は使わない）
  2. お先に失礼します。→ กลับก่อนนะครับ（note：丁寧に ขอตัวกลับก่อน も可）
  3. ちょっといいですか。→ ขอเวลาสักครู่ได้ไหมครับ（少しお時間いいですか）
  4. 手伝ってもらえますか。→ ช่วยหน่อยได้ไหมครับ
  5. ありがとうございます、助かりました。→ ขอบคุณมากครับ ช่วยได้เยอะเลยครับ
  6. すみません、遅くなりました。→ ขอโทษที่ช้าไปหน่อยนะครับ
  7. 急がせてすみませんが、今日中にお願いします。→ ขอโทษที่เร่งนะครับ แต่ขอวันนี้นะครับ
  8. お昼、一緒に行きませんか。→ ไปกินข้าวเที่ยงด้วยกันไหมครับ
- その他候補：すみません、私のミスです → ขอโทษครับ ผมพลาดเองครับ／タイ語はまだ下手なので、ゆっくり話してください → ผมยังพูดไทยไม่เก่ง ช่วยพูดช้าๆ หน่อยนะครับ／遠慮しないでください → ไม่ต้องเกรงใจนะครับ／週末はどうでしたか → เสาร์อาทิตย์เป็นยังไงบ้างครับ。
- 避けるズレ：お疲れ様・よろしくの直訳／毎朝 สบายดีไหม（久しぶりの相手にしか言わない）／宗教・政治・家族の話題／砕けすぎ（จ้า、ป่ะ）／客向けの改まりすぎ（ต้องขอโทษ を社内で連発しない）／お礼・謝罪が ขอบคุณ／ขอโทษ 単独で終わる（一言足す：ช่วยได้เยอะเลย／ผมพลาดเอง）。

### S09（12文）「翻訳して」対応の定型 — title「翻訳して対応」／「เมื่อถูกขอให้แปล」
- ねらい：翻訳を頼まれたときの「説明・保留・確認」。日本語の間接表現をタイ人に噛み砕く「文化の緩衝材」。日本語特有の婉曲（検討します／難しいです／善処します）の「本音」を説明する文を最低3つ入れる。ここがこのセットの核。語を引用せず คำนี้／ประโยคนี้／ที่หัวหน้าพูด で指す（§5.3）。
- 骨格：#2 #5 #10。
- 必ず入れる一言：
  1. この言葉は、日本語では丁寧な言い方です。→ คำนี้ในภาษาญี่ปุ่นเป็นคำสุภาพครับ
  2. 直訳するとこうですが、本当の意味は少し違います。→ แปลตรงตัวได้แบบนี้ แต่ความหมายจริงต่างนิดหน่อยครับ
  3. ニュアンスとしては、かなり急いでいます。→ โทนของประโยคนี้คือค่อนข้างรีบครับ（この文のトーンはかなり急いでいる、です）
  4. 日本側の意図は、確認したいだけです。→ ทางญี่ปุ่นแค่อยากเช็คให้ชัวร์ครับ（日本側はただ確実に確認したいだけです）
  5. 確認してから正確に訳します。→ ขอเช็คก่อน แล้วจะแปลให้ถูกต้องนะครับ
  6. これは断っているのではなく、検討中という意味です。→ อันนี้ไม่ได้ปฏิเสธนะครับ หมายถึงกำลังพิจารณาอยู่ครับ
  7. この文は、私も意味に自信がありません。→ ประโยคนี้ผมเองก็ไม่แน่ใจความหมายครับ
  8. 要点だけ訳しますね。→ ขอแปลเฉพาะประเด็นหลักนะครับ
- その他候補：これは丁寧な言い方で、命令ではありません → อันนี้เป็นการพูดแบบสุภาพ ไม่ใช่คำสั่งครับ／怒っているわけではありません → ไม่ได้ตำหนินะครับ／即答を避けたい、というニュアンスです → ความหมายคือยังไม่อยากตอบทันทีครับ／この言葉はタイ語に直訳しにくいです → คำนี้แปลเป็นไทยตรงๆ ยากครับ。
- 避けるズレ：日本語の語を `th_tts` に入れる／言語学の説明（敬語体系など）／แปล（訳す）と หมายถึง／หมายความว่า（意味する）の混同（直訳＝ตรงตัว、意訳＝แปลตามความหมาย）／「訳せません」で終わる文（必ず保留か代案で終える）／説明の長文化（Level 3 は3文まで）。

### S10（15文）商社の商品語彙 — title「商品の語彙」／「คำศัพท์สินค้า」
- ねらい：語彙を**文の中で**覚える。1文に語彙1つ（Level 3 で2つまで）。用語は §2.7 に固定。メーカー／代理店／型番／仕様書／サンプル／カタログ／納入／検収／請求書／注文書／生産終了品／代替品／在庫切れ・次回入荷。
- 骨格：#1 #3 #7 #9。
- 必ず入れる一言：
  1. うちはこのメーカーの正規代理店です。→ บริษัทเราเป็นตัวแทนจำหน่ายอย่างเป็นทางการของผู้ผลิตรายนี้ครับ
  2. 型番を教えていただけますか。→ ขอทราบรหัสสินค้าได้ไหมครับ
  3. 仕様書をお送りします。→ เดี๋ยวส่งเอกสารสเปคให้นะครับ
  4. サンプルを手配します。→ ผมจะจัดสินค้าตัวอย่างให้ครับ
  5. 納入後、検収をお願いします。→ หลังส่งของแล้ว รบกวนตรวจรับด้วยนะครับ
  6. 請求書は月末にまとめて発行します。→ ใบแจ้งหนี้จะออกรวมกันสิ้นเดือนครับ
  7. 注文書をいただいてから手配します。→ พอได้รับพีโอแล้ว ทางเราจะจัดการให้ครับ
  8. 在庫切れですが、代替品があります。→ ของหมดครับ แต่มีสินค้าทดแทนครับ
- その他候補：次回入荷は来月です → ล็อตหน้าจะเข้าเดือนหน้าครับ／カタログを添付します → แนบแคตตาล็อกไปให้ด้วยนะครับ／代替品は仕様が同等です → สินค้าทดแทนสเปคเทียบเท่ากันครับ／うちは代理店で、メーカーではありません → บริษัทเราเป็นตัวแทนจำหน่าย ไม่ใช่ผู้ผลิตครับ。
- 避けるズレ：単語の羅列（必ず動詞付きの文）／実型番・実メーカー名／FA機器の製品名（PLC等）を並べる語彙集にしない（商社の「手続き語彙」を優先）／請求書＝ใบแจ้งหนี้、税務インボイス＝ใบกำกับภาษี、納品書＝ใบส่งของ を混ぜない／S03 と同じ文の再掲（S03 は納期・価格、S10 は書類・手配で分ける）。

## 8. 起草の手順とセルフチェック

1. 起草前に、その文を「誰に」言うか決める（客／メーカー／スタッフ／上司の通訳）。
2. セットの「必ず入れる一言」を先に書き、骨格ごとに差し替え版を足して目標文数にする。§2.9 で他セットとの重複を確認。
3. 各文で §3 の音節数を数えて level を付ける。23音節以上は割る。
4. `th` を書いたあと、§5 の置換だけで `th_tts` を作る（それ以外は一字一句同じ）。
5. `reading` は §4 の規則で語ごとに。§4.7 の頻出語表と一致させ、ครับ＝クラップ を最後に独立させる。
6. `note` は §6 の型で1論点・40字目標。
7. `uv run tools/generate.py check` を通す。
8. `uv run tools/generate.py build S0X --dry` で分数を見る（1文≈20秒。12文≈4分、15文≈5分、20文≈7分。`--dry` の推定は TTS を3.5秒固定で計算するので実測よりやや短め）。
9. 生成後、数字・略語・外来語を含む文だけ音声を聴き、TTS の誤読があれば `th_tts` の分かち書きで直す。要検証の id 一覧を添える。

**セルフチェック（提出前に全文で確認）**
- [ ] 実名・実型番・実価格・端数金額・年が無い（§2.10 の grep を実行）
- [ ] 文数が目標どおりで、「必ず入れる一言」が全て入っている
- [ ] `th` と `th_tts` が置換以外で一致している。`th_tts` が空でない
- [ ] `th_tts` に英字・数字・記号が無い／`reading` にカタカナ・スペース・ー 以外が無い
- [ ] 文末 ครับ が全文にある（S04 の数字句を除く）。1文に ครับ は2回まで。ค่ะ／ครับผม が無い
- [ ] ต้อง／กรุณา／โปรด／ฉัน／ท่าน の混入が無い（grep）。客向けの文に ไม่ได้ の言い切り・裸の命令形が無い
- [ ] 同じ骨格が2回以上出ていて、隣り合っていない。同じタイ語文が他セットに無い
- [ ] Level 配分が §3 の表の ±1。最初の3文と最後の1文が Level 1。Level 3 の直後が Level 1
- [ ] 用語が §2.7 に揃っている（納期・見積書・PO・請求書・在庫・代替品）
- [ ] `jp` が30字（Level 3 は40字）以内で、括弧・「〜」・「/」・単位記号が無い
- [ ] `note` が1論点・40字目標・言い直しになっていない
- [ ] `title` が8字以内で記号が無い（冒頭で読み上げられる）

## 9. daily（`/thai`・inbox）で使うとき

- `set`＝日付（`2026-10-01`）、`id`＝`D20261001-01` の形、`title`＝その日の短い見出し、3〜8文。多ければ残りは inbox に残して翌日へ。
- 文体・用語・カタカナ・`th_tts`・note・禁止事項は本ガイドと同じ。inbox の「（スタッフに）」などのメモは相手決めに使い、`jp` には入れない。実名・実価格は一般化する（「A社」→ ลูกค้า、金額は「約」か切りのいい数）。
- level は §3 で判定する（daily でも「まずこれ」の目安になる）。
- 既存 daily の読み（クラップ／パイナイ）や level（1）は本ガイド以前のもの。次に触るときに §3・§4 に合わせて直す。
