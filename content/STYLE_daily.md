# STYLE_daily — `/thai`（daily）用の要約

daily を作るときはこれを読む。正本は `content/STYLE.md`（決定事項は同じ）。迷ったら末尾の索引から正本を引く。

## 1. JSON と check

```json
{"set": "2026-10-01", "title": "納期の相談", "title_th": "คุยเรื่องกำหนดส่ง", "sentences": [
 {"id": "D20261001-01", "jp": "…", "th": "…", "th_tts": "…", "reading": "…",
  "note": "…", "tags": ["客先", "説明"], "level": 1}]}
```

- set は日付（バンコク時間）。id は `D`＋日付8桁＋`-`＋2桁連番で、全ファイル通して重複禁止（同じ日に追記するなら続き番号）。title は8字以内、読み上げられるので記号・英字・「／」「〜」なし。1日3〜8文、残りは inbox に残す。`"done": true` は覚えた文（復習・週まとめから外れる）。
- tags＝[場面, 機能]。場面：客先 社内 通訳 電話 会議 日常 翻訳。機能：依頼 確認 報告 説明 数字 品質 挨拶 謝罪 語彙 締切。
- check で落ちる：空欄／level が1〜3以外／th_tts に英字・数字・括弧・引用符／reading にカタカナ・ー・半角スペース以外（「、」「。」「-」も）／note 61字以上（タイ語の母音・声調記号も1字）／jp・th・note に FORBIDDEN の社名。
- th と th_tts は語順・語彙を一致させ、違いは本書 §9 の置換だけ。同じでも th_tts にコピーを入れる。

## 2. 話者・文末

- 男性・日本人の営業。通訳でも ครับ。一人称は ผม だけ。主語に出すのは自分の意思・約束、上司や客との対比、謝罪・断りのときだけ（依頼・確認・数字句には付けない）。「うち」は ทางเรา／บริษัทเรา（เรา 単独は不可）。
- 文末：…ครับ 言い切り／…นะครับ 柔らげ／ช่วย…ด้วยนะครับ 依頼／…ได้ไหมครับ お願い・可能性／…ใช่ไหมครับ 念押し／…ไหมครับ・…หรือเปล่าครับ Yes/No（後者が柔らかい）／…หรือยังครับ もう〜した？／รับทราบครับ・ได้ครับ 了解。
- ครับ は1節に1つ（2節で計2回まで）。同じ文末を4文続けない。不可：ครับผม、ค่ะ／คะ、จ้า／คับ／ป่ะ／อ่ะ、มั้ย（→ไหม）、「?」。ๆ は後ろにだけスペース。

## 3. 相手（文ごとに決める）

inbox のメモ「（客に）」「（スタッフに）」「（上司の通訳で）」で決め、jp には入れない。メモが無ければ jp の語（お客様に／部長が言うには／〜しておいて）で決める。
- **客**：ขอ…／รบกวน…／ช่วย…ได้ไหมครับ、質問は ไม่ทราบว่า…。語は แจ้ง・สินค้า・ตรวจสอบ。納期は ประมาณ で（断言しない）。不可：命令形・ต้อง・เอา・ไม่รู้（→ไม่ทราบ）・ช่วย…หน่อย・ของ・บอก。不良は สินค้าที่มีปัญหา。
- **メーカー**：ขอสอบถาม…／รบกวนช่วยเร่ง…ให้หน่อยนะครับ（買う側なので少し押せる）。
- **社内スタッフ**：軽い ช่วย…หน่อยครับ／標準 ช่วย…ด้วยนะครับ／後でよい ฝาก…ด้วยนะครับ／手間・急ぎ รบกวน…ด้วยครับ／上司・日本側の締切だけ ต้อง…นะครับ＋理由。กรุณา／โปรด は言わず、ห้าม は安全ルールだけ。急かすなら ถ้าเป็นไปได้ ขอวันนี้นะครับ。พี่／น้อง で呼ばない。
- **上司の通訳**：หัวหน้าบอกว่า…／หัวหน้าฝากบอกว่า…（伝言）／ทางญี่ปุ่นขอให้…／ผู้จัดการอยากให้…。自分の推量を混ぜず、締切・数量・条件を落とさない。

## 4. 避ける表現・定番

- 置換：กรุณา／โปรด→ช่วย／รบกวน／ขอ、ท่าน／กระผม→คุณ／ผม、書面語 จึง／ดังกล่าว／ซึ่ง／ทำการ／ดำเนินการ→口語（ซึ่ง→ที่）、ไม่ได้ครับ（きっぱり）→คงยากครับ／อาจจะไม่ทันครับ＋代案、เข้าใจไหม→โอเคไหมครับ、อะไรนะ→ขอโทษครับ ยังไงนะครับ、ผิด（原因確定前）→ไม่ตรงกับสเปค／มีปัญหา、ราคาถูก→ราคาพิเศษ、แปลว่า（つまり）→หมายความว่า…、毎回の ผมคิดว่า→น่าจะ、毎回の ขออนุญาต→ขอ＋動詞、受身 ถูก→能動。
- 「大丈夫です」は ได้ครับ（OK）か ไม่เป็นไรครับ（気にしないで）かを決めてから訳す。
- 定番：確認して折り返します ขอเช็คก่อนแล้วจะแจ้งกลับนะครับ（電話は เดี๋ยวโทรกลับนะครับ）／よろしく（依頼）ฝากด้วยนะครับ／お疲れ様です สวัสดีครับ（帰りは กลับก่อนนะครับ）／申し訳ありません（客）ต้องขอโทษด้วยครับ／検討します ขอพิจารณาก่อนนะครับ＋期限／〜ということですね หมายความว่า…ใช่ไหมครับ

## 5. 外来語・用語統一表

- 会話の外来語はタイ文字で（括弧は客向け・書面）：เช็ค（ตรวจสอบ）、คอนเฟิร์ม（ยืนยัน）、สเปค（ข้อกำหนด）、ออเดอร์（คำสั่งซื้อ）、ดีเลย์（ล่าช้า）、เคลม、อัปเดต、แชร์。th に残せる英字は PO NG OK QC MOQ VAT mm kg だけ。型番・ブランド・メーカー名は書かず รุ่นนี้／รหัสนี้。

**用語統一表**（揺らさない。括弧は別形）

## 6. 日本語側（jp）

- 実際に口にする話し言葉、です・ます体で「。」で終える。inbox の文は意味を変えずに整える。Level 1〜2 は30字以内、3 は40字以内。
- 訳が一意に決まるよう目的語・期限・相手を語で入れる（「確認します」→「在庫を確認して折り返します」）。
- 括弧の注記、「〜」「/」「%」「mm」「kg」「15:30」を書かない（→から・または・パーセント・ミリ・キロ・15時半）。「1日」は「月初」。数字は算用数字でよい。

## 7. level（タイ語側で判定）

長さと構造の**高い方**。音節は発音で数え ครับ・นะ も含める（สัปดาห์ 2、ใบเสนอราคา 5）。
- **1**：10音節以下。骨格1本＋差し替え、接続なし。新語0〜1、数字は2桁まで
- **2**：11〜16音節。骨格＋追加1つ（接続 แล้ว／ก่อน／ถ้า／เพราะ／หลังจาก・期限・数字・専門名詞のどれか）。新語1〜2、数字1つ
- **3**：17〜22音節。2節（条件・理由・伝聞）か追加2つ以上か婉曲の置き換え。新語2〜3、数字2つ・万単位・小数。23音節以上は2文に割る
- 定型（เดี๋ยว…แล้วจะ…กลับ、ขอ…ก่อนนะครับ）は骨格1本。通訳の前置き付きは中身＋1。万単位の金額・บ่าย／ทุ่ม の時刻・日付＋月名は最低2。
- 例：ขอเช็คก่อนนะครับ（5）→1／หัวหน้าบอกว่าอยากเริ่มตั้งแต่อาทิตย์หน้าครับ（12・伝聞）→2／สินค้าตัวนี้ใช้เวลาส่งมอบประมาณสี่สัปดาห์หลังจากสั่งซื้อครับ（19）→3

## 8. カタカナ読み（reading）

一貫性を優先し声調記号は付けない。1語＝1トークン（複合語も1つ）、語間と節の切れ目は半角スペース、ครับ は独立。カタカナ・小書き・ー・スペースのみ（「・」「ヴ」も使わない）。同音は区別しない（ไม่＝ไหม＝マイ）。数字はカナ、略語はタイ式（QC キウシー、NG エンジー）、ๆ は繰り返す。外来語はタイ人の発音（ลีดไทม์ リートタイ、แวต ウェット）。jp の3倍を超えたら文を分ける合図。
- **長母音**（綴りで機械的に）：ー付き＝า ี ื ู เ- แ- โ- -อ เ-อ เ-ิ。ーなし＝ะ ิ ึ ุ เ-ะ แ-ะ โ-ะ เ-าะ -ั ไ ใ เ-า -ำ と暗黙母音（เก้า ガオ、ก็ ゴ、ทำ タム）。二重母音もーなし（เ-ีย イア、เ-ือ／-ัว／-ว- ウア）。เอ＝แอ はエ段、โอ＝ออ はオ段、เออ＝อือ はウ段（คือ クー）。
- **有気・無気**（決定事項）：ก ガ行／ข ค ฆ カ行、จ ジャ行／ฉ ช ฌ チャ行、ด ฎ ダ行、ต ฏ と ถ ท ธ ฐ ฑ ฒ はどちらもタ行、บ バ行、ป と ผ พ ภ はどちらもパ行、頭の ง ンガ行。ほか ร ล ฬ ラ行、ว ワ・ウィ・ウェ・ウォ、ย ญ ヤ行、ห ฮ ハ行、ฟ ฝ ファ行、ส ศ ษ ซ と ทร サ行。ห นำ／อ นำ は無視（อยาก ヤーク）。
- **子音の連続**：二重子音（กร คร ปร พร ตร กล คล ปล พล กว คว）は1字目をウ段（ความ クワーム）。母音字の無い連続は「ア」を挿入（สบาย サバーイ）。
- **末子音**：-n（น ณ ญ ร ล ฬ）と -ng はン、-m はム。-k（ก ข ค）／-t（ด ต ถ ท จ ช ส ศ ษ ฎ ฏ ธ）／-p（บ ป พ ฟ ภ）は短母音のあと ッ＋ク・ト・プ、長母音・二重母音のあと ッなし（มอบ モープ）。語中で同系統の子音が続けば「ッ」だけ（รับผิดชอบ ラッピットチョープ）、別系統なら「ット」＋次（ทั้งหมด タンモット）。-y／-w：ไ ใ アイ、-าย アーイ、-อย オーイ、เ-า アオ、-าว アーオ、แ-ว エーオ、เ-ย ウーイ、-ิว イウ、เ-็ว エオ。์ の付いた字は無音。
- **数字・時間**（固定）：ヌン ソーン サーム シー ハー ホック ジェット ペート ガオ シップ、エット（เอ็ด）、イーシップ（ยี่สิบ）、ローイ パン ムーン セーン ラーン。モーン（โมง）、バーイ（บ่าย）、トゥム（ทุ่ม）、ティアン（เที่ยง）、クルン（ครึ่ง）、ナーティー、チュアモーン、チャーオ（เช้า）、イェン（เย็น）。

## 9. th_tts（Niwat の読み上げ用）

タイ文字・スペース・ๆ だけ。記号（, . / - : ! ? % ฿ ฯ、タイ数字）も語に置き換えるか消す。例：th「สั่งขั้นต่ำ 100 ชิ้นครับ」→ th_tts「สั่งขั้นต่ำหนึ่งร้อยชิ้นครับ」、reading「サン カンタム ヌンローイ チン クラップ」。
- **数字**：1,500 หนึ่งพันห้าร้อย、11 สิบเอ็ด、21 ยี่สิบเอ็ด、20 ยี่สิบ。万は換算（1万 หนึ่งหมื่น、10万 หนึ่งแสน、100万 หนึ่งล้าน、25万 สองแสนห้าหมื่น）。2.5 สองจุดห้า、10% สิบเปอร์เซ็นต์。口語（พันห้า、มิล、โล）は使わず note で触れる。単位は正式形（มิลลิเมตร、กิโลกรัม、個 ชิ้น、台 ตัว、箱 กล่อง、枚 ใบ、1個あたり ต่อชิ้น）。
- **日付・時刻**：15日 วันที่สิบห้า、月末 สิ้นเดือน、月初 ต้นเดือน、月名は正式形（ตุลาคม。th も略さない）、金曜までに ภายในวันศุกร์、〜から〜まで ตั้งแต่…ถึง…。時刻は会話体系（เก้าโมงเช้า、สิบโมงครึ่ง、เที่ยง、บ่ายโมง、บ่ายสามโมง、สี่โมงเย็น、หนึ่งทุ่ม）、24時間制は使わない。年は入れない。
- **略語・記号**：PO พีโอ、NG เอ็นจี、OK โอเค、QC คิวซี、VAT แวต、LINE ไลน์、คุณ A คุณเอ。% เปอร์เซ็นต์、. จุด、/ ต่อ、〜 ถึง。? ! , " - ( ) は消す。日本語の語は入れない。
- **分かち書き**：th と同じ位置（節の切れ目）にスペース。แล้ว／แต่／ถ้า の前、ก่อน の後に1つ。単語ごとには切らない。ครับ は前の語に付ける。TTS が語を誤って切るときだけ th_tts に足す（th は触らない）。読みが怪しい語は要検証として報告する。

## 10. note（目標40字・60字超で落ちる）

「なぜその言い方か」を1点だけ。型は `骨格または語＝意味。理由／使い分け／落とし穴`（体言止め・2文まで）。
- 例：เดี๋ยว〜ก่อน＝「まず〜してから」。折り返しの定番／ตรวจสอบでなくเช็ค。電話では口語が自然／ต้องだと命令調。ช่วยで依頼になる
- 不可：jp の言い直し、文法用語、「丁寧な表現です」「よく使います」、2論点、です・ます、声調記号、実名、タイ語を2語以上並べる（代替は1つ「〜も可」まで）

## 11. 禁止事項（公開リポジトリ）

- 社名 → うち・弊社＝บริษัทเรา／ทางเรา。客 → お客様＝ลูกค้า（inbox の「A社」も）。人名 → 役職語、どうしても要れば คุณ A。
- メーカー・ブランド・製品名・型番（架空の英数字も）→ รุ่นนี้／รหัสนี้。
- 価格・数量はキリのいい数（100、500、1,500、25,000、10%）か「約」。実額に見える端数と値引き交渉の文は入れない。地名・工場名・特定の製品カテゴリ・年も入れない。
- 最後に jp・th・note・title を見て、大文字始まりの英単語・4桁以上の端数・「様」「社」付きの固有名が0件であること。
